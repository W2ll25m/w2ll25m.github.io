Enginnering courses

Circle radius and center estimation

With a set of points representing the results of an experiment, if we know that the result is a circle, we can estimate the parameter R (radius) and G (center) of the circle by uniform random draws of R and G in a certain interval. We can compare the results of this method against the simple way of estimating the parameters of the circle by calculating the barycenter and the average distance of the points to it. The experience that we conducted show that the first method seems more reliable.

Simulation done in Matlab. In black, the dots that are given to us, in red the initial circle used to generate the dots, in blue, the circle estimated be calculating the average R and G and in green, the circle with the uniform random draws method.

Guessing game

The computer has to guess in the least attempts possible the number that the player (the user) has chosen between 1 and 999. It has to ask if the player has chosen a number at the start of each turn and asks if the player wants to continue at the end. It uses dichotomy to guess the number and the program has been developped using the program refinement method to fullfil the specifications given.
